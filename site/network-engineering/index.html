Network engineering and connectivity

Before cloud I worked in telecom: 4G and LTE rollout, MPLS, and Alcatel-Lucent 7750 SR service routers. Because of that, cloud networking problems rarely surprise me.

Start a conversation See the track record

Scope

What I take on

Hybrid connectivity

Joining an office, a data centre and a cloud estate without ending up with one flat network where everything can reach everything.

Segmentation

VPC and subnet design, security groups and routing that follow an actual trust model instead of whatever was quickest at the time.

VPN estates

pfSense, WireGuard and OpenVPN, site-to-site and remote access, built so the people running them can operate them day to day.

Load balancing and failover

HAProxy and Keepalived for services that cannot afford a single point of failure.

Method

How it runs

  1. 01

    Draw the real topology

    Almost every network engagement starts with finding out the diagram is out of date. That week of discovery is usually the most useful one.

  2. 02

    Default deny, then open deliberately

    Segmentation is only worth anything if the default is closed. Retrofitting that takes work, but the work has an end.

  3. 03

    Document it for the person on call

    If nobody but you can reason about a network, it is a liability, however elegant it is.

Evidence

Where I have done this before

  • Patchman Scaled Redis, PostgreSQL and Nginx for high availability using Keepalived and HAProxy across a Linode estate.
  • Alcatel-Lucent / Nokia 4G and LTE rollout and network monitoring, then telecom KPI data work, with MPLS and 7750 SR at carrier scale.
  • Certification CCNA (Routing & Switching), Cisco Security Green Belt, and Alcatel-Lucent Certified Field Expert in MPLS and 7750 SR.

Fit

Probably worth a conversation if

  • Your cloud network grew organically and is now effectively flat.
  • You need a site-to-site or remote-access VPN estate someone can actually maintain.
  • A hybrid setup needs joining up without opening everything to everything.
  • You want a segmentation model designed once, by someone who did this before cloud.
